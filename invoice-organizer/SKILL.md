# 发票整理

## 适用范围

用于整理当前文件夹第一层的中文电子发票 PDF：

- 批量重命名发票。
- 按报销目标金额选择一组发票并移动到金额文件夹。
- 对无法读取金额或开票日期的文件生成需人工处理清单。

不用于：

- 非 PDF 发票或图片发票。
- 需要递归扫描子目录的发票整理。
- 金额、日期都无法读取，且用户没有提供人工补充信息的文件。

## 核心规则

- 只扫描当前工作目录第一层的 `.pdf` / `.PDF` 文件。
- 不递归扫描子目录，不处理已移动到金额文件夹中的文件。
- 文件名统一为 `{金额}_发票_{YYYYMMDD}.pdf`，例如 `19.59_发票_20260516.pdf`。
- 金额优先从文件名提取；文件名没有金额时，再从 PDF 正文提取。
- 日期以 PDF 正文中的开票日期为准，不以文件名日期或文件修改时间为准。
- 金额全部按“分”计算，避免浮点误差。
- 无法读取金额或日期的文件不要改名、不要移动，列入人工处理报告。
- 如重命名后发生同名冲突，在文件名末尾追加 `_2`、`_3` 等稳定后缀，避免覆盖。

## 操作流程

用户说“整理当前文件夹发票名称”时：

1. 确认当前工作目录就是用户要整理的发票目录。
2. 扫描当前目录第一层 PDF。
3. 读取每张发票的金额与开票日期。
4. 对可识别的发票按 `{金额}_发票_{YYYYMMDD}.pdf` 重命名。
5. 将无法识别金额或日期的文件写入人工处理报告。

用户说“按金额 {目标金额} 汇集发票并移动到金额文件夹”时：

1. 扫描当前目录第一层 PDF。
2. 读取每张发票金额；无法读取金额的文件写入人工处理报告。
3. 用“分”为单位计算所有可用发票组合。
4. 选择与目标金额绝对差值最小的一组。
5. 若差值并列，依次优先：
   - 超过或等于目标金额的组合。
   - 文件数更少的组合。
   - 按文件名稳定排序后更靠前的组合。
6. 将选中的 PDF 移动到 `金额_{目标金额}` 文件夹，例如 `金额_271.45`。

## 推荐脚本

优先使用随技能提供的脚本：

```powershell
python C:\Users\jimmy\.codex\skills\invoice-organizer\scripts\organize_invoices.py rename
python C:\Users\jimmy\.codex\skills\invoice-organizer\scripts\organize_invoices.py collect --target 271.45
```

脚本默认在当前工作目录执行。执行前先确认 shell 的当前目录就是发票所在目录。

## 人工处理报告

当存在无法读取金额或日期的 PDF 时，生成 `发票整理_人工处理报告.md`，内容至少包含：

- 原文件名。
- 无法处理原因，例如“未读取到金额”或“未读取到开票日期”。
- 建议用户人工补充金额或日期后再重新执行。

如果没有需要人工处理的文件，不强制生成空报告。
